# Background music

Drop an MP3 here named `wedding-theme.mp3` (or change `music.src` in `js/config.js`).

Until a file is added, the music button plays a soft built-in instrumental
(a tanpura drone with a gentle Raag Bhupali melody) so it always works.

Keep the file small (under ~3 MB, 128 kbps is plenty) so the page stays fast on mobile data.
Only use music you have the rights to share.
